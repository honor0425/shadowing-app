# 跟讀練習 Shadowing Player

英文跟讀練習工具：分句播放、重複練習、自動抓 YouTube CC 字幕、錄音對比。

## 功能
- 上傳影片 + SRT/VTT 字幕分句跟讀
- YouTube 網址自動抓取 CC 字幕
- 每句重複 N 次 + 暫停等待跟讀
- 錄音 & 波形顯示 & 保存下載

## 本地開發

```bash
npm install
npm run dev
```

開啟 http://localhost:3000

## 部署到 Vercel

1. 把這個資料夾推到 GitHub（見下方說明）
2. 到 vercel.com 登入 → New Project → 選這個 repo → Deploy

完成！Vercel 自動處理 Next.js 建置。
